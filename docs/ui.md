# iCreate Email — original interface brief

## Principles

- One composition: reading and composing mail should feel like a single calm surface, not a dense
  admin console.
- Brand first: **iCreate Email** is the hero-level identity in About and empty states; no third-party
  bird or ribbon clone.
- Slate field, ivory glyphs, blue accent underline — match the 2026 icon system.
- At least two intentional motions later (list→thread open, compose sheet) — ship with restraint.

## Layout direction (not Thunderbird / Outlook)

- Avoid a classic three-pane clone as the default skin.
- Prefer a focused inbox list with a reading stage that can go full-bleed; folder navigation secondary.
- Compose as a dedicated sheet / space, not a cramped nested pane mimicking Outlook.
